# Roadmap

OpenTRAP is built in the open. Every feature below is laid out in the interface but not implemented yet; using it in the app opens a dialog that names the same reference code. Pick one and open a pull request on [the main project](https://github.com/opentrap/opentrap) to build it. Accepted work is merged with full credit. To discuss a feature or ask for it to be prioritised, [open an issue](https://github.com/opentrap/opentrap/issues).

Reference codes are stable: quote one in an issue or pull request title. Large features are split so that each entry can be finished on its own.

This file is generated from the registry in `src/opentrap/ui/Unbuilt.java`, which also drives the Roadmap tab under Discover; do not edit it by hand.
